# Catalog - User Stories v1

### US-CAT-001: Search Products by Name
**As a** customer
**I want to** search products by name
**So that** I can quickly find what I need

**Acceptance Criteria:**
- Real-time search results
- Results show: Name, Price, Image, Store
- Search highlights matching text
- Results limited to service area

### US-CAT-002: Filter by Category
**As a** customer
**I want to** filter products by category
**So that** I can browse by type

**Acceptance Criteria:**
- Multi-level category filtering
- Apply multiple filters
- Show product count
- Clear filters easily

### US-CAT-003: View Product Details
**As a** customer
**I want to** view detailed product information
**So that** I can make informed purchases

**Acceptance Criteria:**
- Display images, description, price
- Show ratings and reviews
- Display stock status
- Show expiry date
- Display seller info

### US-CAT-004: Sort Products
**As a** customer
**I want to** sort products by price/rating
**So that** I can find best deals

**Acceptance Criteria:**
- Sort by: Price (Low-High, High-Low)
- Sort by: Ratings (High-Low)
- Sort by: Newest First
- Sort by: Best Selling

### US-CAT-005: Bulk Product Upload
**As a** vendor
**I want to** upload multiple products via CSV
**So that** I don't add each manually

**Acceptance Criteria:**
- Support CSV format
- Template provided
- Validation for duplicates
- Success report shown

### US-CAT-006: Update Product Information
**As a** vendor
**I want to** update product details
**So that** information stays current

**Acceptance Criteria:**
- Edit: Name, Description, Price
- Edit: Category, Tags, Image
- Changes effective immediately
- Update history maintained

### US-CAT-007: Mark Out of Stock
**As a** vendor
**I want to** mark products as out of stock
**So that** customers cannot order them

**Acceptance Criteria:**
- Out-of-stock products hidden
- Status updated real-time
- Backorder option available

### US-CAT-008: Featured Products
**As an** admin
**I want to** highlight featured products
**So that** popular items get visibility

**Acceptance Criteria:**
- Feature up to 20 products
- Rotation every 6 hours
- Analytics available
