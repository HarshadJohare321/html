# Pickup - User Stories v1

### US-PICK-001: Schedule Pickup
**As a** customer
**I want to** schedule when to pick up my order
**So that** I can collect at my convenience

**Acceptance Criteria:**
- Available time slots shown (30 min intervals)
- Next 7 days available
- Confirmation sent
- Pickup ID provided
- SMS reminder sent

### US-PICK-002: Pickup Readiness
**As a** customer
**I want to** know when my order is ready for pickup
**So that** I can go collect it

**Acceptance Criteria:**
- Notification sent when ready
- SMS + Email
- 2-hour pickup window
- Auto-cancel if not picked up
- Reattempt option

### US-PICK-003: Collect Pickup
**As a** customer
**I want to** collect my order
**So that** I receive my items

**Acceptance Criteria:**
- Show order ID at store
- Items handed by staff
- Physical verification
- Receipt provided
- QR scan confirmation

### US-PICK-004: Pickup Location
**As a** customer
**I want to** see pickup location details
**So that** I can find the store

**Acceptance Criteria:**
- Store address shown
- Map with directions
- Store operating hours
- Contact number
- Parking information

### US-PICK-005: Modify Pickup Time
**As a** customer
**I want to** change my pickup time
**So that** I can be flexible

**Acceptance Criteria:**
- Modify button before pickup
- New time slot selection
- Confirmation sent
- Free modifications

### US-PICK-006: Cancel Pickup
**As a** customer
**I want to** cancel pickup
**So that** I don't have to collect

**Acceptance Criteria:**
- Cancellation allowed before ready status
- Full refund
- Cancellation reason
- Confirmation email
