# Dispute - User Stories v1

### US-DISP-001: Report Issue
**As a** customer
**I want to** report an issue with my order
**So that** it can be resolved

**Acceptance Criteria:**
- Issue type selection (Quality, Delivery, Payment, Other)
- Description field (1000 chars)
- Photo/video upload
- Select affected order
- Submit confirmation

### US-DISP-002: Dispute Status Tracking
**As a** customer
**I want to** track my dispute status
**So that** I know progress

**Acceptance Criteria:**
- Status shown: Submitted, Investigating, Resolved
- Timeline displayed
- Expected resolution date
- Updates via notification

### US-DISP-003: Dispute Resolution
**As a** customer
**I want to** receive refund or credit
**So that** I'm compensated for issue

**Acceptance Criteria:**
- Refund/Credit decision notified
- Amount shown
- Processing time: 5-7 days
- Original payment method used
- Confirmation email sent

### US-DISP-004: Appeal Dispute
**As a** customer
**I want to** appeal dispute decision
**So that** I can challenge unfair decision

**Acceptance Criteria:**
- Appeal button available
- Appeal reason required
- Additional evidence upload
- Escalation to higher admin
- Decision within 7 days

### US-DISP-005: Dispute History
**As a** customer
**I want to** see my dispute history
**So that** I can reference past issues

**Acceptance Criteria:**
- List of all disputes
- Filter by status/date
- Details of each dispute
- Resolution details
- 12 months history

### US-DISP-006: Chat with Support
**As a** customer
**I want to** chat with support about my dispute
**So that** issues are resolved faster

**Acceptance Criteria:**
- Chat button on dispute page
- Live chat with support
- Chat history maintained
- Response within 5 minutes
