# Vendor Management - User Stories v1

### US-VM-001: Vendor Registration
**As a** shopkeeper
**I want to** register as a vendor
**So that** I can sell my products

**Acceptance Criteria:**
- Registration form: Store name, Owner name, Phone, Email
- Document upload: PAN, GST, Shop license
- Bank details: Account, IFSC, Beneficiary
- Submission confirmation
- Admin review within 48 hours

### US-VM-002: Store Setup
**As a** vendor
**I want to** setup my store profile
**So that** customers know about my store

**Acceptance Criteria:**
- Store name editable
- Store description (500 chars max)
- Store logo upload
- Operating hours setup
- Contact phone/email

### US-VM-003: Service Area Configuration
**As a** vendor
**I want to** define my delivery zones
**So that** customers know where I deliver

**Acceptance Criteria:**
- Map-based zone selection
- Radius-based zones (1km increments)
- Multiple zones supported
- Delivery time per zone

### US-VM-004: Vendor Dashboard
**As a** vendor
**I want to** see my sales analytics
**So that** I can monitor performance

**Acceptance Criteria:**
- Daily/weekly/monthly sales
- Order count and status
- Revenue vs target
- Top selling products
- Customer ratings

### US-VM-005: Payment Settlement
**As a** vendor
**I want to** receive payments for my sales
**So that** I can sustain my business

**Acceptance Criteria:**
- Weekly settlement
- Automatic bank transfer
- Settlement report available
- Deductions shown (commission, returns)
- Settlement history 12 months

### US-VM-006: Vendor Policies
**As a** vendor
**I want to** set my cancellation policy
**So that** customers understand my terms

**Acceptance Criteria:**
- Cancellation window: 0-30 mins post order
- Cancellation charges: 0-20%
- Return period: 0-30 days
- Return condition requirements

### US-VM-007: Bulk Operations
**As a** vendor
**I want to** perform bulk operations
**So that** I can manage efficiently

**Acceptance Criteria:**
- Bulk price update
- Bulk stock update
- Bulk product disable/enable
- Bulk import from CSV

### US-VM-008: Support Ticket
**As a** vendor
**I want to** raise support tickets
**So that** issues can be resolved

**Acceptance Criteria:**
- Category selection
- Description and attachments
- Priority level
- Response within 24 hours
