## 🚀 Quick Start

1. **Download** the project ZIP
2. **Extract** to a folder
3. **Open** `index.html` in your web browser
4. **Search** and **navigate** through modules
5. **Click** any link to view documentation

## 📖 Documentation Structure

### Core Documents
- **ACCEPTANCE_CRITERIA_INDEX_v1.md** - All acceptance criteria
- **USE_CASE_CATALOG_v1.md** - Enterprise use cases
- **ENTERPRISE_USER_STORIES_INDEX_v1.md** - Master user stories index
- **BUSINESS_RULES_CATALOG_v1.md** - Business rules and constraints
- **TRACEABILITY_MATRIX_v1.md** - Requirements to use cases mapping

### Module Documentation
Each module folder contains:
- `USE_CASES_[module]_v1.md` - Module-specific use cases
- `USER_STORIES_[module]_v1.md` - Module-specific user stories

## 📱 How to Use the Portal

1. **View Quick Links** - Access core documentation directly
2. **Search Modules** - Use the search box to filter by name
3. **Expand Modules** - Click module cards to reveal documents
4. **Open Documents** - Click links to view markdown files
5. **Navigate Back** - Use browser back button to return to portal

## 🔍 Search Tips

- Search by module name: `payment`, `inventory`
- Search by document type: `user stories`, `use cases`
- Partial matches work: `deliv` finds delivery
