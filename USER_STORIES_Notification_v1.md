# Notification - User Stories v1

### US-NOT-001: Order Confirmation
**As a** customer
**I want to** receive order confirmation
**So that** I know my order is placed

**Acceptance Criteria:**
- SMS sent immediately
- Email sent with order details
- Push notification on app
- Order number in notification
- Tracking link included

### US-NOT-002: Delivery Updates
**As a** customer
**I want to** receive delivery updates
**So that** I'm informed of progress

**Acceptance Criteria:**
- Notification when dispatched
- Alert when out for delivery
- ETA message with time
- Delivery OTP message
- Delivered confirmation

### US-NOT-003: Promotional Messages
**As a** customer
**I want to** receive promotional offers
**So that** I know about deals

**Acceptance Criteria:**
- Opt-in required
- Frequency: Max 5 per week
- Easy opt-out
- Personalized based on history

### US-NOT-004: Payment Confirmation
**As a** customer
**I want to** receive payment confirmation
**So that** I have record

**Acceptance Criteria:**
- SMS with amount and order
- Email with receipt
- Transaction ID mentioned
- Payment method shown

### US-NOT-005: Notification Preferences
**As a** customer
**I want to** control notification channels
**So that** I receive only preferred notifications

**Acceptance Criteria:**
- SMS toggle
- Email toggle
- Push notification toggle
- Time slot selection (Do not disturb)
- Preference saved

### US-NOT-006: Support Ticket Updates
**As a** customer
**I want to** get support ticket updates
**So that** I know issue status

**Acceptance Criteria:**
- Notification when ticket opened
- Update when staff responds
- Resolution notification
- Rating request after close

### US-NOT-007: Refund Notification
**As a** customer
**I want to** be notified of refund
**So that** I know when to expect money

**Acceptance Criteria:**
- Refund initiated notification
- Processing notification
- Completion notification with amount
- Bank processing time mentioned

### US-NOT-008: Wishlist Notification
**As a** customer
**I want to** get alerts for wishlist items
**So that** I can buy when available/on sale

**Acceptance Criteria:**
- Back in stock notification
- Price drop notification
- Sale notification
- Optional for each item
